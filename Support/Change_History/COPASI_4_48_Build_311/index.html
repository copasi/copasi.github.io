Version 4.48.311

Release Date: October 22, 2026

New Features since COPASI 4.47 (Build 309)

  • This is only a bug fix release there are no new features

Bug Fixes and Enhancements since COPASI 4.47 (Build 309)

  • Graphical User Interface (CopasiUI)
    • The Time Scale column is now always positive in all tabs containing information about a Jacobian.
  • Simulation Engine
    • Fixed calculation of Jacobian in cases where the a species concentration is exactly zero.
    • The pseudo random number generation and sampling of distribution is now done with classes provided by the C++ standard.
  • Standards
    • SBML: Fixed crash when loading a model containing unsupported delays.
  • Language Binding
    • Assured that all warnings created during import of SBML files are accessible.
